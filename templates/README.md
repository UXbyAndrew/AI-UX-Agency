# UX Suite Templates

These templates support the UX skill suite. They are designed to turn audit, research, strategy, and analysis work into consistent, decision-ready deliverables.

## Template Groups

- `reports/`: executive summaries, audit reports, scorecards, finding tables, and roadmaps.
- `research/`: research plans, interview guides, usability test plans, synthesis, personas, JTBD, and journey maps.
- `audits/`: specialized audit deliverables for heuristics, accessibility, IA, content, and conversion.
- `strategy/`: product strategy briefs and related strategy artifacts.
- `working/`: evidence logs and internal support artifacts.

## Quality Standard

Every template should help the UX suite separate evidence from assumptions, connect findings to user and business impact, and produce recommendations that are clear enough to act on.

## Standard Finding Format

Use this format whenever documenting UX issues:

| Field | Description |
|---|---|
| Finding | Clear issue statement |
| Evidence | Screenshot, quote, data point, observation, or source |
| Severity | Critical, High, Medium, Low |
| User impact | How it affects task success, confidence, comprehension, or accessibility |
| Business impact | How it affects conversion, activation, retention, cost, risk, or trust |
| Recommendation | Specific fix or next action |
| Effort | Low, Medium, High |
| Confidence | High, Medium, Low |
| Owner | Design, Product, Engineering, Content, Research, Data, or cross-functional |
