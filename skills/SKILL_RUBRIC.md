# UX Skill Rubric

This rubric defines the quality bar for every `skills/ux-*/SKILL.md` file in the UX suite. A skill is not considered production-ready unless it scores 10/10 across this rubric and would earn confident sign-off from a Senior UX Designer, Director of Design, and Principal UX Designer.

## Scoring Scale

Each category is scored 0-10. A world-class skill must score 10 in every category, not merely average 10 overall.

- **10:** Clear, rigorous, specific, operational, evidence-aware, and ready for real client/product work.
- **8-9:** Strong but missing specificity, reconciliation logic, or implementation detail.
- **6-7:** Useful but generic; needs stronger workflow, output contract, or agent integration.
- **4-5:** Prompt-like, inconsistent, or insufficiently senior.
- **0-3:** Unclear, unsafe, misleading, or not operationally usable.

## 10/10 Criteria

### 1. Mission Clarity
The skill has a precise purpose, clear boundaries, and a strong reason to exist as a separate workflow.

A 10/10 skill:
- states the design/product problem it solves
- names what it owns and does not own
- avoids overlap with adjacent skills unless handoff logic is explicit
- can be understood by a designer, PM, engineer, researcher, or executive

### 2. Agent Integration
The skill uses the agent layer as source expertise, not decorative references.

A 10/10 skill:
- lists primary and supporting agents
- defines what each agent contributes
- includes a sequence for when those perspectives are applied
- explains how contradictions between agents are reconciled
- prevents duplicate or conflicting recommendations

### 3. Evidence Discipline
The skill separates observed facts, user-reported evidence, analytics, comparative examples, expert inference, and unknowns.

A 10/10 skill:
- labels evidence type
- states confidence clearly
- avoids pretending assumptions are facts
- recommends the next validation step when evidence is weak
- makes uncertainty useful rather than vague

### 4. Methodological Rigor
The skill uses mature UX/product methods appropriate to the work.

A 10/10 skill:
- uses a structured workflow
- applies relevant frameworks without becoming academic
- handles ambiguity, missing inputs, and partial evidence
- supports both fast critique and deep analysis where appropriate
- produces repeatable results across different products

### 5. Actionability
The skill turns diagnosis into prioritized action.

A 10/10 skill:
- gives recommendations that a team can execute
- includes severity, effort, confidence, owner, and validation
- distinguishes quick wins from strategic work
- avoids vague advice like “improve clarity” without specifying how
- connects recommendations to task completion, accessibility, trust, conversion, retention, or product value

### 6. Output Contract
The skill defines exactly what the deliverable should contain.

A 10/10 skill:
- includes a default output format
- supports optional deeper outputs when needed
- uses consistent sections across the suite
- can generate standalone client-ready documentation
- avoids sprawling, inconsistent deliverables

### 7. Strategic Relevance
The skill connects UX quality to product and business outcomes.

A 10/10 skill:
- identifies user impact and business impact
- considers metrics and decision-making context
- supports prioritization and roadmap logic
- respects constraints and tradeoffs
- avoids design purity disconnected from outcomes

### 8. Implementation Awareness
The skill understands that UX recommendations must survive real delivery.

A 10/10 skill:
- considers engineering, content, analytics, accessibility, support, and operational constraints
- identifies dependencies and owners
- distinguishes design changes from research, content, data, and engineering work
- produces implementation-ready guidance

### 9. Anti-Pattern Resistance
The skill actively prevents common low-quality UX outputs.

A 10/10 skill:
- rejects generic checklists
- rejects invented certainty
- rejects decorative personas, vague journeys, superficial audits, and unprioritized issue dumps
- avoids over-prescribing when evidence is limited
- includes “do not do this” rules specific to the skill

### 10. Executive Readiness
The skill can produce outputs credible to leadership and useful to working teams.

A 10/10 skill:
- starts with implications, not trivia
- gives clear priority and rationale
- communicates tradeoffs directly
- supports decisions, not just observations
- can be summarized for stakeholders without losing rigor

## Board Review Standard

Every skill must satisfy these review lenses before finalization.

### Senior UX Designer Sign-Off
The skill is practical, usable, detailed, and capable of improving real screens, flows, content, and interactions.

### Director of Design Sign-Off
The skill is strategically framed, cross-functional, prioritizable, and aligned with business and product outcomes.

### Principal UX Designer Sign-Off
The skill is systems-minded, evidence-disciplined, scalable, and mature enough to handle ambiguity, complexity, and tradeoffs.
