# UX Skills

This folder contains the workflow layer for the UX suite. The top-level `ux/SKILL.md` routes commands into these skills. Each skill uses the specialist agent files in `ux/agents/` as expert lenses, then reconciles their perspectives into a single decision-grade deliverable.

## Included Skills

| Skill | Purpose |
|---|---|
| `ux-audit` | Full UX/product audit with prioritized findings and roadmap |
| `ux-quick` | Fast senior UX snapshot |
| `ux-flow` | Task, funnel, and workflow analysis |
| `ux-research` | Research planning, testing, synthesis, and validation |
| `ux-personas` | Evidence-based personas, JTBD, segments, and need states |
| `ux-heuristic` | Structured usability/heuristic evaluation |
| `ux-accessibility` | Accessibility and inclusive design review |
| `ux-ia` | Navigation, taxonomy, labeling, and findability |
| `ux-content` | UX writing, content clarity, empty/error states, labels |
| `ux-conversion` | Funnels, CTAs, forms, trust, and conversion friction |
| `ux-onboarding` | Activation, first-run, setup, and product education |
| `ux-dashboard` | Dashboards, data UX, tables, charts, and reporting |
| `ux-commerce` | Ecommerce discovery, product detail, cart, checkout, post-purchase |
| `ux-enterprise` | B2B SaaS, admin, power-user, permissions, and complex workflows |
| `ux-design-system` | Components, tokens, states, documentation, and governance |
| `ux-journey` | Journey mapping and service experience analysis |
| `ux-strategy` | Product strategy, opportunity framing, roadmap, and metrics |
| `ux-report` | Markdown report compilation |
| `ux-report-pdf` | PDF-ready report package |

## Quality Standard

See `SKILL_RUBRIC.md`. Every skill is written to score 10/10 across mission clarity, agent integration, evidence discipline, methodological rigor, actionability, output contract, strategic relevance, implementation awareness, anti-pattern resistance, and executive readiness.
